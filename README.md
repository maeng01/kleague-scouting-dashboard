# K리그 스트라이커 스카우팅 & 브랜드 적합도 대시보드 (파일럿)

> **"이 선수를 어떻게 관리하고, 어떤 브랜드와 연결할 것인가"** 를 공개 데이터로 뒷받침하는 의사결정 보조 도구.
> 스포츠 에이전시 / 브랜드 엔도스먼트 직무 지원용 포트폴리오.

**라이브 데모:** https://kleague-striker-scouting.streamlit.app
**대상:** 2026 K리그1 스트라이커 22명 (`Pos=FW`, 90분 환산 출전 ≥ 5)

---

## 왜 이 프로젝트인가 — 기획 방향 재설정

처음 기획([`football_talent_identification_scouting_model.md`](football_talent_identification_scouting_model.md))은
**ML 기반 유소년 잠재력 예측 + 역사적 백테스팅**이었다. 아래 이유로 방향을 바꿨다.

| 문제 | 판단 |
|---|---|
| 유소년 historical dataset은 공개 확보가 사실상 불가능 (생존편향 없는 표본을 구할 수 없음) | ML 예측의 전제 자체가 성립 안 함 |
| 지원 직무(선수 매니지먼트·스폰서십 유치·브랜드 엔도스먼트)가 실제로 필요로 하는 건 예측 정확도가 아니라 **의사결정 근거** | "예측 모델"이 아니라 "판단 보조 도구"로 재정의 |
| 업계도 에이전시·브랜드가 직접 모델을 만들기보다 Nielsen Sports·Hookit·Wyscout 같은 상용 플랫폼을 구매해 씀 | 대체가 아니라 **"그 분석 로직을 이해하고 구현해봤다"는 역량 증명**으로 포지셔닝 |

→ 결과물은 **경기력 맥락 + 마케팅 가치 + 에이전시 관점 추천**을 한 화면에서 보는 대시보드.

## 무엇을 하는가 — 3개 모듈

선수 한 명을 고르면 3개 탭이 뜬다. **Yago Cariello (울산, 27세, 2026 xG 리그 1위)** 예시.

### ① Scouting Snapshot — 경기력 맥락 (비중 작게)

- **레이더 6축은 "과정" 지표만**: xG/90 · 슈팅/90 · 유효슈팅/90 · xA/90 · 키패스/90 · 드리블성공/90.
  이 지표들은 8~12경기면 표본에 안정된다.
- **"결과" 지표(득점/90, 결정력 = 득점−xG, 전환율)는 레이더에서 빼고** 별도 표 + 변동성 경고와 함께.
  1.5~2시즌 이상 누적돼야 신뢰 가능하기 때문.
- **신뢰도 티어** 항상 병기: 🟢 안정(1800분+) / 🟡 중간(900~1800) / 🔴 낮음(<900).
  22명 중 90s ≥ 15는 4명뿐 — 풀 절반이 저신뢰 구간이라는 걸 숨기지 않고 표시.
- 2025 완료 시즌 대비 추세 비교(14명 커버).

> Yago: xG/90 95p · 유효슈팅/90 96p · 드리블/90 88p (풀 상위권) ↔ xG 대비 실득점 −0.21/90 (불운/결정력은 표본 더 필요)

### ② Brand Fit & Marketability — 핵심

**Marketability Score** = `도달×0.25 + 참여율×0.40 + 언론노출×0.20 + 팬덤폭×0.15`
참여율에 최대 가중치. 파일럿 8명은 참여율 **실측**(공개 IG 게시물별 (좋아요+댓글)/팔로워).

**카테고리 적합도** = 이미지 태그 × 활성화 계수. 7개 업종(스포츠웨어·게임/e스포츠·테크·금융·F&B·여행/라이프스타일·자동차)별 점수.

**언론 노출**은 1–5 수동 버킷을 **네이버 뉴스 검색 건수로 교체 완료**(파일럿 11명) — NAVER API HUB
(NCP)의 뉴스 검색 `total`을 고정 질의로 수집, `log10(news_count)`으로 media 축에 반영
([`src/collect_naver.py`](src/collect_naver.py), [가이드](data/collect/COLLECT_NAVER.md), 질의어 근거
[`naver_queries.csv`](data/collect/naver_queries.csv)). 주민규 38K · 무고사 19K · 마르캉(말컹) 9K · 디오구 862 등.
`total`은 전체 기간 누적이라 '최근 화제성'과는 다르고, 외국인 표기 미정착 선수(오로보·흘레이할)는 실제보다 낮게 잡힘.

**최근 뉴스 타임라인** — 같은 API로 관련도순 헤드라인을 받아 **제목에 선수명이 든 기사만** 필터해
선수 페이지에 최신 6건 표시(스탯 아니라 맥락 — 득점·부상·이적·대표팀). 뉴스 본문 파싱으로 스탯을
끌어오는 건 하지 않는다 — API가 본문을 안 주고, 뉴스 산문에서 xG 같은 과정지표는 애초에 안 나온다.

> Yago: Marketability 68.3 → 게임·e스포츠 75.4 / 스포츠웨어 63.5.
> 근거 태그: 젊은 유망주·성장 서사, 화려한 플레이·쇼맨십.

### ③ Agency Recommendation

과정지표 percentile + 신뢰도 티어 + 연령 + 전년 대비 추세 + Marketability → **규칙 기반** 강점 / 리스크 / 전략 / 우선순위(★).
**ML 예측 아님.** 1페이지 스폰서 제안서 초안(.docx) 자동 생성.

> Yago ★★★★☆: "3~4년 계약으로 전성기 구간 가치 극대화 · 숏폼 강화로 참여율 방어 · 게임/e스포츠 카테고리 우선 접촉"

## 핵심 발견

**1. 팔로워 규모와 참여율 (파일럿 8명 실측 — IG 게시물 좋아요·댓글 직접 집계)**

| 선수 | 팔로워 | 참여율 | 메모 |
|---|---:|---:|---|
| Yago Cariello | 9.1K | 20.7% | 소규모·고밀도 |
| Bruno Mota | 8.7K | ~15% | 좋아요만 (댓글 제한 계정) |
| Stefan Mugoša | 21.7K | 10.5% | |
| Tiago Orobó | 20K | 8.0% | |
| Patryk Klimala | 45.4K | 6.7% | |
| Joo Min-kyu | 29.6K | 3.9%\* | \*댓글 비활성, 좋아요만 |
| Marcão | 1,034K | 3.2% | adidas football 계약 |
| Diogo | 78K | ~1.3% | 78K 치고 낮음 — 비활성 팔로워 추정 |

→ **소규모 계정(9K–45K)에서는 팔로워가 많을수록 참여율이 낮다** — 1만 미만인 Yago·Bruno Mota는
참여율 15–20%, Klimala(4.5만)는 6.7%. **밀도 높은 소규모 팬덤**은 소액·다건 협찬·젊은 층 캠페인에서 오히려 유리하다.
참여율에 최대 가중치를 두는 이유. K리그 팬덤 특성 반영해 참여율 정규화 상단을 7% → 12%로 상향.

→ 양극단 두 경고: **Marcão(103만·adidas)** 는 100만 계정에서 3.2%로 이례적으로 높아(대개 1% 미만)
"작지만 밀도 높은 팬덤" 논리가 필요 없는 유일한 선수. 반대로 **Diogo(78K·1.3%)** 는 팔로워는 큰데
반응이 눌린 케이스 — 도달만 크고 참여가 낮으면 협찬 전환이 안 나온다. 참여율 가중이 두 경우를 자동으로
분리한다(Diogo Marketability 42 vs Bruno Mota 63).

**좋아요 비공개 계정**(Hleihil `abdallahlehel` 1.8만, Vitor Gabriel `v_gabriel09` 16.9만)은 팔로워만 확인,
참여율은 계정주만 볼 수 있어 미측정. **Lee Hojae**는 본인 개인 Instagram이 없어 팬페이지만 존재한다.

**2. 과정 지표와 결과 지표는 안정화 속도가 다르다**

시즌 중반 스냅샷에서 득점/90·결정력으로 선수를 평가하면 표본 노이즈를 실력으로 오독한다.
그래서 레이더(선수 프로필)에는 과정 지표만 쓰고, 결과 지표는 "참고 · 변동성 큼"으로 분리했다.

| 선수 bio (신장·발·시장가치·계약·용품 계약) | Transfermarkt·나무위키 (수동) | 22/22 (일부 필드 비공개) |
| SNS·참여율 | Instagram 공개 게시물 (2026-08 meta 태그·2026-09 로그인 세션) | 파일럿 11명 중 8명 참여율 실측(+2명 팔로워만) |

- **percentile은 이 22명 스트라이커 풀 내부 기준** — "K리그 전체 대비"가 아님.
- **자동 스크래핑 없음**: FBref 봇 차단 / `data.kleague.com` robots.txt 금지 / FotMob ToS 금지.
  사람이 브라우저에서 복사, 코드는 파싱·재계산만.
- **시즌 라벨 주의**: 기초 CSV 파일명은 `2025`지만 골·도움이 FotMob 2026과 정확히 일치 →
  실제로는 2026 시즌 진행 중(약 25R) 스냅샷. 완료된 2025는 별도 비교 레이어.

```bash
# 1. FotMob 리더보드를 markdown 표로 2026 Stats/ · 2025 Stats/ 에 저장
```

## 한계 (숨기지 않고 명시)

- 표본이 작고 시즌 진행 중 → "파일럿". 라운드 스냅샷임을 전제.
- 22명 중 고신뢰(90s ≥ 15) 4명뿐 → 과정/결과 지표 분리 + 신뢰도 티어로 대응.
- SNS는 공개 API 제약으로 수작업. 참여율 실측 8명. Lee Hojae는 개인 계정 없음 확인.
- Brand Fit·카테고리 적합도는 정성 판단이 섞인 반정량 지표 — **예측이 아니라 의사결정 보조**.
- 이 도구가 **못 하는 것**: 계약금 규모 산정, 브랜드 세이프티(구설 이력) 스크리닝,
  팔로워 인구통계(연령·성별·지역), 콘텐츠 적합도 분석. 실무용은 여기에 딜 비교·오디언스 데이터를 얹어야 함.
- ML Potential Model / Historical Backtesting은 향후 확장 로드맵으로만 남김.
